# Maintainability review — отдельный подагент сопровождения

Статус: **проектируемое расширение; ничего не реализовано**. Этот каталог описывает будущую проверку повторяющихся групп данных и нового отдельного подагента ревью. Он не заявляет о работающем поведении, не меняет текущий контракт вердикта и не разрешает блокировать коммиты до реализации и приёмки.

## Что проверяем

Пять (или иные) значения, которые всегда передаются вместе и описывают одну сущность, размножены по многим узлам, вызывающим и промежуточным функциям. Изменение сущности требует согласованных ручных правок в каждом месте. Это проблема сопровождения, а не обязательно ошибка выполнения.

## Почему отдельный подагент

Нынешний поиск дефектов запрещает структурные замечания к функционально корректному коду (см. `agents/review-risk-hunter.md`). Такой класс проблем в текущем контракте не проверяется, поэтому нужен отдельный участник с собственным планом проверки, вызовом инструментов, рефлексией и явными доказательствами.

## Принятые решения (2026-11-01)

Парсер JS/TS становится прямой зависимостью; первая поставка проверяет JS/TS и Python; подтверждённый пункт с доказанной ценой сопровождения блокирует коммит.

## Что делает ревью быстрым

Дорогую часть — поиск повторяющихся групп — выполняет детерминированный разбор синтаксического дерева по файлам из staged-снимка, без модели. Кандидаты берут начало в изменённых путях, а поддержка считается по всему снимку: иначе группа из шестнадцати узлов при изменении двух из них не дойдёт до порога. Модель (подагент) получает готовый список кандидатов с точными местами и проверяет смысл только по этим местам, а не читает проект целиком.

## Границы

- Не рефакторит и не переписывает код автоматически.
- Блокирует коммит по умолчанию, но только при доказанной цене сопровождения: названном согласованном изменении и местах правок, приоритете `P2` и если пункт не является чистой пересылкой. Вердикт меняют машинные поля ответа, а не формулировки в тексте отчёта; пункт без такой цены остаётся рекомендацией.
- Ограничен по времени и размеру: файл сверх предела, недоступный для разбора синтаксис и усечённый обход печатаются как неполный охват, а не как «кандидатов нет», и сами по себе коммит не блокируют.
- Не заявляет о полном охвате языков: неподдержанный язык сообщается явно, а не молча пропускается.
- Не добавляет собственную модельную политику: роль и модель принадлежат OMP (`model: "@task"`).
- Не расширяет существующий контракт вердикта: подтверждённые элементы сопровождения идут отдельным разделом отчёта.
