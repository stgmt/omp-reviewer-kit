# Доставка без патчинга репозиториев — критерии приёмки

Дата: 2026-11-03. Каждый критерий проверяется исполнением; ссылка ведёт на файл и тест, который падает при нарушении.

## AC-01 — Шаблон хука не содержит версии выпуска

- Маркер шаблона соответствует `# omp-reviewer-kit hook-format v<N> body-sha256:<64 hex>`.
- Строка `hook vX.Y.Z` в шаблоне отсутствует.
- Проверка: `tests/hook-ownership.test.mjs` — «its marker names the hook format and not the release»; `scripts/check-layout.mjs` падает на шаблоне с версией выпуска.

## AC-02 — Дайджест покрывает тело без маркера

- Дайджест не учитывает ни формат-маркер, ни прежний маркер выпуска.
- Мутант «дайджест считает маркер» (`hook-digest-keeps-marker-line`) убит.
- Проверка: `tests/hook-ownership.test.mjs` — правка тела ломает владение, смена маркера не ломает.

## AC-03 — Хук прежнего выпуска распознаётся и мигрирует один раз

- Формат такого хука читается как `0`, владение подтверждается.
- `healTargets` заменяет его на текущий формат; повторный вызов не пишет ничего.
- Мутант «прежний маркер не разбирается» (`hook-legacy-marker-not-owned`) убит.
- Проверка: `tests/hook-ownership.test.mjs` — «written by an earlier release … migrates once».

## AC-04 — Отредактированный хук не перезаписывается

- Хук с несовпадающим дайджестом считается чужим: состояние `conflict`, файл не меняется.
- Проверка: `tests/hook-ownership.test.mjs` — «edited under an unchanged marker … nothing is rewritten».

## AC-05 — Доставка обновляет только этот плагин

- Команда OMP вызывается как `omp plugin upgrade omp-reviewer-kit`.
- Проверка: `tests/deliver.test.mjs` — успешный сценарий строит таблицу вызовов и не содержит безусловного `upgrade`.

## AC-06 — Сломанный хост не считается пропущенным

- `probe` различает `absent` (ENOENT) и `failed` (есть, но не отвечает).
- Мутант «любая ошибка = отсутствует» (`deliver-broken-host-counted-skipped`) убит.
- Проверка: `tests/deliver.test.mjs` — OMP и Claude Code в сломанном состоянии дают `ok: false`.

## AC-07 — Код возврата доставки отражает результат

- CLI возвращает `0` только если все проверки прошли.
- Мутант «CLI всегда успешен» (`deliver-cli-always-zero`) убит.
- Проверка: `tests/deliver.test.mjs` — два дочерних процесса: с формат-маркером код 0, с маркером выпуска код 1.

## AC-08 — Инвариант проверяется по форме

- Маркер любой версии выпуска отклоняется проверкой доставки.
- Мутант «проверка отключена» (`deliver-release-marker-accepted`) убит.
- Проверка: `tests/deliver.test.mjs` — «any release marker fails, not just the current one».

## AC-09 — Повторная синхронизация не пишет файлы

- Первая синхронизация после 0.28.0 перевела парк на формат-маркер.
- Вторая синхронизация на тех же байтах: 0 записей `pre-commit:updated` / `pre-commit:written`.
- Проверено вручную на 81 зарегистрированном репозитории; `doctor` — «all current».

## AC-10 — Установленный выпуск несёт формат-маркер

- После `omp plugin install` версия 0.28.0: `templates/githooks/pre-commit` в установленном плагине начинается с `hook-format v1`.
- `node scripts/deliver.mjs` в чистом дереве 0.28.0: 3/3 проверки пройдены.
