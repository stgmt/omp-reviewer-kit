# plugin-delivery

Central specification for installing, updating, migrating and uninstalling `omp-reviewer-kit` on
Claude Code, Codex CLI, OMP and OpenCode.

- [SPEC.md](SPEC.md) — the specification: host capability facts with sources, generated manifests,
  install/update/verify/uninstall commands, migration table, blast radius, failure modes, acceptance
  criteria, and the open questions with the test that settles each.

This directory is plain Markdown authored in the repository; it is not served through the spec MCP
door.
